{{ bot_name }} — Privacy Policy

This policy is specific to {{ bot_name }}, a Discord bot, and describes exactly what it collects and why.

What {{ bot_name }} is

{{ bot_name }} is a private Discord bot that runs in a single, specific Discord server (it will not accept an invite to any other server). It provides a fictional-currency casino/economy game, moderation tools, a support-ticket system, and configurable activity logging for that server's staff.

Data collected through Discord

  • Discord user ID and display name — to know whose balance, warning, or ticket belongs to whom.
  • Server membership and roles — to check permissions (e.g. is someone staff) and to run moderation actions.
  • Message content — read only (a) to recognize commands typed with this server's prefix, and (b) if the server's staff turn on message logging, to copy the text of an edited or deleted message into that server's own private staff log channel. Message content is never written to a file or database, and never leaves the server it was posted in.

Data stored outside Discord

The bot's operator hosts a small amount of data on their own server, tied to your Discord user ID, so the bot's features work between sessions:

  • Your in-game balance, bank, inventory, business, and achievement progress (all fictional currency — no real money or payment information is ever involved).
  • Moderation warnings issued against you: the reason text, which staff member issued it, and when.
  • Server configuration chosen by staff (which channels/roles are used for what) — this isn't about you personally, but is stored the same way.

None of this is sold, shared with third parties, used for advertising, or used to train AI/ML models. It exists only to make the bot's own features work, for staff of the one server this bot runs in.

Deleting your data

Run /deletemydata (or !deletemydata, using this server's prefix) at any time to permanently delete your stored balance/inventory/business data and warning history. You can also ask the server's staff to do this for you. If the bot is ever removed from the server, all server-specific data is deleted along with it.

Children's privacy

{{ bot_name }} is intended for use within Discord under Discord's own Terms of Service, which require users to meet Discord's minimum age requirement. The bot does not knowingly collect additional data from children beyond what's described above.
